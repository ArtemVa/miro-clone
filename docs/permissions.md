# Права

Роли: владелец (`owner`), редактор (`editor`), наблюдатель (`viewer`). Права проверяет сервер: на каждый запрос и на каждое изменение по WebSocket. Фронт прячет кнопки, которые роли недоступны, но это только удобство, а не защита.

## Откуда берётся роль

- Пространство. У каждого участника пространства своя роль. Доски пространства доступны его участникам с этой же ролью.
- Отдельная доска. Доступ к одной доске можно дать человеку, который в пространстве не состоит, например по ссылке-приглашению. Участнику пространства роль на доске может поднять его роль на этой доске. Роль на доске только `editor` или `viewer`: своего владельца у доски нет, доской управляют владельцы пространства.
- Итоговая роль на доске: большая из двух, роли в пространстве и роли на доске. Порядок: `owner`, потом `editor`, потом `viewer`.
- Действия с самим пространством (создать в нём доску, участники, переименование, удаление) проверяем только по роли в пространстве. Доступ к отдельной доске на них не влияет. Копия доски создаётся в пространстве, поэтому копировать доску можно только с ролью не ниже редактора в пространстве.

Роли в коде: `WorkspaceRoleSchema` и `BoardRoleSchema` в `packages/contracts`, в базе: `workspace_members.role` и `board_members.role`.

## Что можно каждой роли

| Действие                                     | Владелец | Редактор | Наблюдатель |
| -------------------------------------------- | -------- | -------- | ----------- |
| Смотреть доску                               | да       | да       | да          |
| Менять содержимое доски                      | да       | да       | нет         |
| Комментировать                               | да       | да       | да          |
| Создавать доски в пространстве               | да       | да       | нет         |
| Переименовывать и копировать доску           | да       | да       | нет         |
| Удалять доску в корзину                      | да       | да       | нет         |
| Восстанавливать из корзины, удалять навсегда | да       | нет      | нет         |
| Восстанавливать версию доски                 | да       | да       | нет         |
| Создавать ссылки, отзывать доступ к доске    | да       | нет      | нет         |
| Управлять участниками пространства           | да       | нет      | нет         |
| Переименовывать и удалять пространство       | да       | нет      | нет         |

## Владельцы пространства

- Создатель пространства становится его владельцем.
- Владельцев может быть несколько. Последнего владельца нельзя удалить или понизить.
